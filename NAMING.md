# Test Naming Convention

## Test Method Naming

I will use the following pattern:

MethodName_Scenario_ExpectedResult

Example:
CalculateTotal_WithValidItems_ReturnsExpectedTotal

## Test Class Naming

I will use the following pattern:

ClassNameTests

Example:
CalculatorTests

## General Rules

- Test names should be descriptive and easy to understand.
- Each test should focus on one behavior.
- Use clear names that describe the scenario and expected result.
